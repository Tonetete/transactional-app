# Web frontend — phase 04a (Next.js)
Next.js app (apps/web) with a deposit form and a live list of transactions, built with atomic design; simulated login. Bank stays simulated. CDK is phase 04b.

## Specs
- S1: "formulario del depósito y que vaya mostrando la lista de las transacciones"
- S2: "a la hora de implementar los componentes se siga un patrón atomic design y modularizable para ir componiendo las páginas mediante estos componentes atómicos" (atoms -> molecules -> organisms -> templates -> pages, each layer imports only from lower ones)
- S3: "Ruta de login simulada" — API endpoint that mints a dev JWT, enabled only by an explicit env flag, never in production by default.
- S4: Frontend generates the idempotency key ("A unique alphanumeric token generated by the frontend to unambiguously represent user intent") and surfaces contract errors (code, message, correlation_id).
- S5: API gains tenant-scoped GET /v1/deposits (RLS) and CORS for the web origin; contract types shared via @acex/shared.
- S6: "el banco debe seguir siendo simulado"
